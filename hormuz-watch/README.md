# دیده‌بان هرمز — Hormuz Watch

وب‌اپ فارسی (PWA) برای رصد زنده تنگه هرمز از روی گوشی:

- **نقشه زنده پروازها** روی تنگه (مرکز ۲۶٫۵۵، ۵۶٫۲۵ — شعاع ۱۳۰ مایل دریایی)، تازه‌سازی هر ۳۰ ثانیه
  - طبقه‌بندی: مسافری/باری (آبی)، نظامی (نارنجی — `dbFlags` فرد)، پهپاد (بنفش — کال‌ساین FORTE یا نوع‌های Q9/R4/Y6/UAV)
  - کلیک روی هر هواپیما: کال‌ساین، نوع، رجیستر، ارتفاع، سرعت، جهت
  - فیلتر جدا برای هر دسته + حالت دیده‌بانی با هشدار چشمک‌زن و بنر برای تماس‌های تازه
- **ساحل من (گهردو)**: دما، باد و تندباد، رطوبت، ارتفاع و دوره موج، جمع‌بندی ساعت‌به‌ساعت امروز با تاریخ شمسی
- **کشتی‌ها**: خطوط اصلی کشتیرانی تنگه (TSS) و بندرهای مهم روی نقشه. داده زنده AIS رایگانِ قابل‌اعتماد عمومی وجود ندارد و موقعیت ساختگی نمایش داده نمی‌شود.
- **تایم‌لاین رویدادها**: تماس‌های نظامی/پهپاد تازه در `localStorage` گوشی ذخیره و فهرست می‌شوند.

## منابع داده (رایگان و عمومی)

| داده | منبع |
|---|---|
| پرواز ADS-B | [adsb.lol](https://api.adsb.lol/v2/lat/26.55/lon/56.25/dist/130) — mirror: [adsb.fi](https://opendata.adsb.fi) |
| هوا | Open-Meteo Forecast API (`Access-Control-Allow-Origin: *`) |
| موج | Open-Meteo Marine API |
| کاشی نقشه | CARTO Dark Matter (OpenStreetMap) |

### نکته CORS (مهم)
`api.adsb.lol` هدر `Access-Control-Allow-Origin` نمی‌فرستد (تأییدشده با curl در ۲۲ اکتبر ۲۰۲۶)، پس فراخوانی مستقیم از مرورگر ممکن است بلاک شود. اپ زنجیره fallback دارد:
۱) adsb.lol مستقیم ← ۲) adsb.fi مستقیم ← ۳) پراکسی عمومی codetabs به adsb.lol (هدر `ACAO: *` تأییدشده) ← ۴) پراکسی codetabs به adsb.fi.
منبع فعال در نوار وضعیت بالای اپ نشان داده می‌شود.

## نصب روی آیفون
لینک را در سافاری باز کن ← Share ← **Add to Home Screen**. مانیفست + Service Worker برای نصب و بازشدن آفلاینِ پوسته اپ آماده است. داده‌های زنده نیاز به اینترنت دارند.
