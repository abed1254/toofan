# YouTube Focus — حذف تبلیغات و حواس‌پرتی

افزونه کروم (Manifest V3) برای یوتیوب:

- رد خودکار تبلیغات (دکمه Skip رو می‌زنه؛ تبلیغ غیرقابل‌رد رو می‌پره آخرش)
- مخفی‌کردن پیشنهادهای کناری، شورتس، کامنت‌ها، پیشنهادهای پایان ویدیو و فید صفحه اصلی
- پاپ‌آپ با ۶ تا تیک برای خاموش/روشن کردن هر مورد جدا

## نصب

۱. همین پوشه رو دانلود کن (یا کل ریپو رو به‌صورت zip بگیر و این پوشه رو جدا کن).
۲. تو کروم برو به `chrome://extensions`، حالت Developer mode رو روشن کن.
۳. دکمه **Load unpacked** رو بزن و همین پوشه رو انتخاب کن.
